# Агент поиска компаний и их LinkedIn

Находит компании по отрасли и стране (например, iGaming-операторы на Кипре), отсеивает провайдеров и находит страницу компании в LinkedIn. Результат сохраняется в CSV.

## Запуск

```bash
cd agent
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...
python find_companies.py --industry iGaming --country Cyprus --out results/cyprus_agent.csv
```

Параметры: `--segment` (кого включать и кого исключать), `--limit` (сколько компаний искать, по умолчанию 40).

## Как работает

1. **Исследование**: Claude ищет в интернете (web_search / web_fetch) реестры регуляторов, отраслевые СМИ и вакансии, отделяет операторов (B2C) от провайдеров и ищет `linkedin.com/company/...`.
2. **Структурирование**: отчёт переводится в строгую схему (Pydantic).
3. **Экспорт**: ссылки на LinkedIn проверяются по шаблону `/company/`, результат пишется в CSV.

LinkedIn напрямую не парсится: ссылки берутся из поисковой выдачи.

## Готовый результат

`results/cyprus_igaming_operators.csv` — первый список iGaming-операторов с присутствием на Кипре, собранный вручную через веб-поиск (17 компаний, у каждой указана уверенность).

Что важно знать:
- На Кипре лицензируются только **ставки на спорт** (NBA, Class A/B). Онлайн-казино в РК запрещены. Поэтому в список попали два типа компаний: локальные букмекеры с лицензией NBA и международные операторы с офисом на Кипре и лицензией Кюрасао или других юрисдикций.
- Компании, которые включены под вопросом, отмечены в `notes`: Soft2Bet (одновременно оператор и провайдер), Hititbet (Северный Кипр), наземные казино.
